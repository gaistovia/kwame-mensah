# /assets/images

Reserved for locally-hosted image assets.

This demo currently references photography directly from Unsplash's CDN
(see the main README's "Photography" note). Drop optimized local copies
here (and update the `src`/`srcset` attributes in `index.html`) if you'd
rather self-host the imagery for production — recommended before a real
client launch, for both licensing control and load-time reliability.
